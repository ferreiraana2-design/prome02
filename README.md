# prome02

Projeto web estático do site **Prome**.

## Descrição

Este repositório contém a página inicial do projeto **Prome**, desenvolvida em HTML5.

## Como abrir

1. Abra o arquivo `1.html` no navegador.
2. Caso prefira, você pode rodar um servidor local simples na pasta do projeto.

## Estrutura

- `1.html` — página principal
- `README.md` — documentação do projeto
- `.gitignore` — arquivos e pastas ignoradas pelo Git

## Tecnologias

- HTML5
